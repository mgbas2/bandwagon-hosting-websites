## 搬瓦工建站是什么意思？先搞清楚这个概念

搬瓦工卖的是 VPS（虚拟私人服务器）。简单理解：你租一台在海外数据中心运行的服务器，完全由你自己管理，装什么系统、跑什么程序都行。建站的意思，就是在这台 VPS 上安装 Web 服务环境（比如 LNMP 或 LAMP），然后部署 WordPress、Typecho 之类的 CMS，再绑定你的域名，网站就跑起来了。

和虚拟主机的区别：虚拟主机是共享环境，资源有限、功能受限；搬瓦工 VPS 是独立资源，权限完整，你可以跑任何合法程序。

**一句话总结**：搬瓦工 VPS 完全支持建站，适合个人博客、企业官网、外贸独立站、WordPress 站点等几乎所有常见建站场景。

4. **安装宝塔面板**：一行命令搞定，宝塔支持一键安装 LNMP（Nginx + MySQL + PHP）环境，新手友好。
5. **购买并解析域名**：在 Cloudflare 或其他域名注册商购买域名，将 A 记录解析到你的 VPS IP 地址。等待解析生效（一般 5-30 分钟）。

7. **安装 SSL 证书**：宝塔面板内可以一键申请 Let's Encrypt 免费证书，开启 HTTPS。

小内存 VPS（1GB 内存）跑 WordPress 要注意：宝塔面板本身会占用一部分内存，建议开启 Swap 交换分区，同时给 MySQL 做内存限制优化，防止 OOM 崩溃。
